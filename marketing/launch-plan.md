# План запуска

Всё публикует владелец сам со своих аккаунтов. Дни — условные: «День 1» = первый вторник после того, как пройдена подготовка. Платную рекламу не запускать.

## Подготовка (за 1–2 недели до Дня 1)

- [ ] Завести аккаунты: Product Hunt, Hacker News, Reddit, AlternativeTo. На Reddit и HN неделю-две оставлять полезные комментарии — новые аккаунты с одной ссылкой режут фильтры.
- [ ] Проверить путь покупателя на живом сайте: скачать → установить → «Запустить пробный период на 7 дней» → купить ключ (реальную покупку не делать, только дойти до окна Paddle).
- [ ] Проверить ящик support@jackdaw-mail.pro — вопросы пойдут туда.
- [ ] Решить, что сказать про подпись сборок: сейчас первый запуск блокирует Gatekeeper/SmartScreen — это главная причина отказа после скачивания. Тексты в пакете честно об этом предупреждают.
- [ ] Свести README на GitHub с сайтом: там бейдж «Linux | iOS | Android», а на сайте сказано, что этих сборок пока нет. Читатели HN и Reddit открывают репозиторий первым.
- [ ] Добавить в GitHub-репозиторий темы `outlook-alternative`, `imap`, `windows`.

## Что смотреть после каждой публикации

- Логи сайта по `?ref=` — откуда пришли.
- Скачивания на странице релизов GitHub (`gh release view --json assets` показывает `downloadCount`).
- Запуски пробного периода и покупки — в панели Paddle и на сервере лицензий.
- Вопросы в комментариях → в FAQ сайта, если повторяются.

## Чего не делать

- Не просить голосовать, не накручивать, не публиковать с чужих аккаунтов.
- Не публиковать один и тот же текст в несколько сабреддитов в один день.
- Не писать отзывы от имени пользователей и не называть цифры, которых нет.
