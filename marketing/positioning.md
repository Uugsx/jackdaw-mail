# Позиционирование

## Кому продаём (по приоритету)

1. **Уходят с Outlook, но остаются на Exchange.** Офисы и отделы на своём Exchange Server (OWA/EWS), которым не нравится новый Outlook для Windows: веб-обёртка, синхронизация сторонних ящиков через облако Microsoft, исчезновение привычных функций. Им нужны общие ящики, сетевой архив, автоответ, правила на сервере, бронирование переговорных — Jackdaw это умеет.
2. **Малые компании и команды поддержки, продаж, закупок, диспетчерские** — те, кто отвечает клиентам по почте и должен отвечать вовремя. Уникальное: срок ответа в рабочих минутах, очередь неотвеченных, отчёт по скорости ответов. В Outlook, Thunderbird и Spark этого нет.
3. **Пользователи Mac в компаниях на Exchange.** Outlook для Mac и Thunderbird закрывают не всё (у Thunderbird календарь и контакты Exchange пока только через дополнения).
4. **Люди, которым важна приватность и открытый код.** Почта идёт напрямую с сервера на компьютер; клиент открыт (EUPL).
5. **Русскоязычные пользователи за рубежом** — интерфейс на 43 языках, включая русский и украинский.

## Факты, которые можно говорить (проверены по сайту и коду)

- macOS 12+ (Apple Silicon и Intel), Windows 10/11 64-бит. Linux, iOS, Android — пока нет готовых сборок.
- Exchange через OWA, EWS и ActiveSync, общие ящики, сетевой архив на десятки тысяч писем; IMAP; CalDAV/CardDAV; вход через Microsoft, Google, Yahoo, AOL, Fastmail, Mail.ru. Microsoft Graph и JMAP — в тестовом режиме.
- Срок ответа в рабочих минутах с графиком по дням недели, напоминания, очередь неотвеченных, отчёты с выгрузкой в HTML (Pro).
- Звонки (аудио, видео, показ экрана) и чат между пользователями Jackdaw Mail со сквозным шифрованием, группы до 50 человек (Pro).
- Exchange-функции: автоответ, правила на сервере, задачи, заметки, состав рассылок, отправка от имени общего ящика, бронирование переговорных.
- PGP и S/MIME, если есть ключи. Пароли: DPAPI на Windows, Связка ключей на macOS.
- 43 языка интерфейса.
- Открытый код клиента (EUPL-1.2), основан на открытом коде Ben Bucksch / Beonex и других участников.
- Цены: бесплатно для одного ящика; Pro $9.99/мес или $79.99/год за место (1 человек, до 2 устройств), пробный период 7 дней без карты. Оплата через Paddle.

## Чего не говорить

- Не обещать полноценную работу с **Microsoft 365 / Exchange Online** без оговорки: Microsoft отключает EWS для Exchange Online с 1 октября 2026 года, а Graph у нас в тестовом режиме. Формулировка: «Exchange Server (свой сервер) — полностью; Microsoft 365 — через Graph в тестовом режиме».
- Не говорить «подписан Apple / Microsoft». Сборки не заверены: macOS блокирует первый запуск, Windows SmartScreen показывает предупреждение. Лучше сказать об этом заранее, чем ждать вопроса в комментариях.
- Не называть число пользователей, установок, рейтинги, отзывы.
- Не сравнивать с конкурентами за пределами таблицы на сайте (`site/index.html#compare`) — там сформулированы проверенные пункты.

## Частые возражения и честные ответы

| Возражение | Ответ |
|---|---|
| «Не подписано — небезопасно» | Код открыт, сборки делает GitHub Actions в публичном репозитории, контрольная сумма обновления проверяется перед установкой. Подпись Apple и Microsoft — платные сертификаты; говорить о сроках, только если владелец их назвал. |
| «Electron тяжёлый» | Да, это Electron. Взамен — одна кодовая база для Mac и Windows и быстрые обновления. |
| «Зачем платить, если есть Thunderbird» | Для одного ящика Jackdaw бесплатен. Платно — то, чего в Thunderbird нет: срок ответа, отчёты, общие ящики Exchange с календарём, звонки и чат. |
| «Куда уходят мои письма» | Никуда, кроме вашего компьютера: почта идёт напрямую с вашего сервера.
