## Общие правила

- Без выдуманных цифр, отзывов, «тысяч пользователей» и рейтингов. Сейчас у проекта 0 звёзд на GitHub — это нормально для запуска, приукрашивать не нужно.
- Цены везде одинаковые: **$9.99 в месяц или $79.99 в год за место** (место — один человек и до 2 устройств), **7 дней Pro без карты**, один ящик бесплатно навсегда.
- Ссылки: сайт `https://jackdaw-mail.pro`, код `https://github.com/Uugsx/jackdaw-mail`, сборки `https://github.com/Uugsx/jackdaw-mail/releases`.
- Для отслеживания источников добавляйте к ссылке на сайт `?ref=<площадка>` (например `?ref=hn`, `?ref=producthunt`, `?ref=habr`). Сайт этот параметр не обрабатывает, но он виден в логах сервера.
- Платная реклама не запускается.
