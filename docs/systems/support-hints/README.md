# Подсказки пользователю: сценарии и ошибки

Единая система: `app/logic/util/friendlyError.ts` (`describeError` → причина + «что делать» + «Подробности для поддержки»), показ — `Shared/Notice.svelte` / `ErrorMessage.svelte`. Новой системы не заводим: дополняем `textForKind` и `withNetworkAdvice`. Строки — `gt\`...\`` / `$t\`...\``, английский — исходник, русский — в `l10n/locales/ru`.

Статус: ✅ есть · 🟡 частично · ⬜ план · 🔶 делает другая сессия.

## Правила для новых подсказок
- Причина по-человечески → «что делать» → кнопка (`Notice` `onRetry`; для нового действия — добавлять опциональное свойство, не менять существующие).
- Сложное поле — короткая подпись под ним или «?» (`tooltip.ts`), пустое состояние — что это и как заполнить.
- Ошибка в логи/Sentry уходит как есть; на экране — текст + «Подробности для поддержки».
- После добавления строк: ru — в `l10n/locales/ru/messages.json`, остальные языки — fallback на английский.
