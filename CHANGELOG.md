# История изменений

## 0.9.46-dev — 2026-09-30

- Счётчики подпапок дополнительного OWA-ящика проверяются адресным пакетным GetFolder: неполный или устаревший Deep FindFolder больше не останавливает их обновление.
- При открытии shared-папки выполняется проверка сервера даже при «чистом» локальном кеше; короткая синхронизация объединяет новые заголовки из explicit- и delegate-контекстов.
- Обход флагов вложений больше не блокирует загрузку писем, а fallback при отстающем поиске непрочитанных не сканирует многотысячную папку целиком в быстром цикле.

## 0.9.45-dev — 2026-09-30

- Исправлена синхронизация непрочитанных в shared OWA-папках: при расхождении выбирается полный ответ Exchange, совпадающий со счётчиком папки.
- Заголовки shared-писем добираются во втором mailbox-контексте, если первый вернул только часть ItemId; это устраняет разрыв между счётчиком и отображаемыми письмами.
- Сканирование флагов вложений останавливается после обработки всех локально закешированных писем; полная сверка OWA-папки прекращается при зацикливании/достижении предела и не удаляет кеш при неполном результате.

## 0.9.44-dev — 2026-09-30

- Открытая OWA-папка теперь независимо от серверного счётчика периодически проверяет последние письма, чтобы список не зависел от переключения профиля.

## 0.9.43-dev — 2026-09-30

- Исправлена полная сверка shared-папок после уменьшения серверного счётчика.
- Синхронизация заголовков shared-папок теперь использует явный mailbox-контекст и не создаёт ложные непрочитанные письма из неполных ответов Exchange.

## 0.9.42-dev — 2026-09-30

- Исправлена синхронизация счётчика непрочитанных писем с заголовками в shared-папках OWA.
- Пустые или неполные ответы Exchange больше не удаляют локальный список и повторно запрашиваются через явный mailbox-контекст.

## 0.9.41-dev — 2026-09-30

- Ускорено обновление счётчиков дополнительных OWA-ящиков без очереди параллельных циклов.
- Для дерева shared-папок используется mailbox-aware Deep FindFolder, чтобы получать счётчики одним запросом.

## 0.9.40-dev — 2026-09-30

- Исправлено обновление счётчиков папок дополнительных OWA-ящиков через явный mailbox-контекст.
- Добавлен fallback для успешных ответов OWA без сопоставимых папок, чтобы счётчики не замирали без ошибки.

## 0.9.39-dev — 2026-09-30

- Исправлена синхронизация счётчика непрочитанных писем после внешнего изменения статуса письма в OWA.
